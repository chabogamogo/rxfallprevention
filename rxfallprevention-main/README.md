# RxFallPrevention

Kekal Sihat, Kekal Bersedia — bilingual pharmacist-led fall prevention education.

## Run
Open index.html in a browser or run `python -m http.server 8000` from the repository root. No build or external dependencies required.

## GitHub Pages
In repository Settings → Pages, choose Deploy from a branch, main, /(root), then Save. Expected URL: https://chabogamogo.github.io/rxfallprevention/ (not verified live).

## Content
Based on the supplied 31-slide educational module: screening slide 8; medication safety slides 9–16; medication review slides 17–20; prevention slides 21–30. English translations and game questions are adaptations. Clinical review is required before public use, including hypoglycaemia instructions, dietary recommendations and exercise precautions. No institutional logo or original PDF is published.

## Privacy
No analytics, server, registration or persistent health data. Screening and checklist answers are held in memory only.

## Current scope
Static HTML/CSS/JS implementation; five quiz-style games, not graphical hotspot games. Browser, mobile and WCAG conformance testing remain outstanding. Future work: illustrated exercise sequences, richer home hazard game, optional read-aloud, research assessment modules and formal clinical validation.
